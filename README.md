# Edi-webdev — Portfolio Website

Personal portfolio website for **Edi-webdev**, a full-stack web developer building custom websites for small businesses. Live at: https://tuedi593.github.io

## What it does

A single-page site showcasing web development services and selected projects:

- **Hero / About** — intro with call-to-action buttons and service tags
- **Expertise** — 4 service cards: Company Profile Websites, **AI Customer Service (24/7)** — a custom-built assistant trained on the client's own products, pricing and policies (works on website or WhatsApp), Villa & Booking Websites, and Fast/Secure/SEO-friendly builds
- **Portfolio** — 5 featured projects:
  - [JB Trans Lampung](https://jbtranslampung.com) — car rental booking site (PHP, WhatsApp booking)
  - [Bali Bike Adventures](https://balibikeadventures.com) — adventure travel portal (WordPress API, Leaflet JS)
  - [Villa Waha](https://villawaha.com) — luxury villa showcase (PHP, reservation sync)
  - [Villa Ipanema](https://ipanemavilla.com) — high-end real estate gallery (custom plugin, image optimization)
  - [Karang Saujana Estate](https://www.karangsaujanavillas.com) — multi-property reservation system (API integration, calendar sync)
- **Contact** — inquiry form (via Formspree), click-to-copy email, and WhatsApp chat button

## Tech stack

- Plain **HTML5, CSS3, JavaScript** — no frameworks, no build step
- Google Fonts (Outfit, Space Grotesk)
- Formspree for form submissions
- Static hosting on **GitHub Pages**

## Project structure

```
├── index.html    # Entire page (all sections + SVG icons)
├── styles.css    # All styling (orbs, animations, responsive layout)
├── script.js     # Nav, scroll progress, email reveal, form handling
├── images/       # Avatar and project screenshots
└── README.md
```
